## keys
Some time ago (I think three years ago), during a personal conversation with [Zed Shaw](https://zedshaw.com/), he encouraged (actually he challenged me to encourage me) to write a port in Python of his [Buttons the Computer](https://lcthw.dev/learn-javascript-the-hard-way/buttons-computer) which he had developed as part of a course he was creating.

I did not understand what VMs or "computers" were at that time. And trying to understand them pushed me into a rabbit hole.

This is my attempt to finish that challenge in Python.

### Usage
Zed's computer required you to program the computer using "buttons" (mouse clicks). Well, mine require you to write a program for the computer using the "keys" in your keyboard (duh).
